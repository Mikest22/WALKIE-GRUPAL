# WALKIE PRO - ESTRUCTURA LIMPIA

Sube estos archivos a la raíz del repositorio WALKIE-GRUPAL:

index.html
style.css
app.js
firebase-config.js
webrtc.js
ui.js
audio.js
manifest.json
service-worker.js

Crea la carpeta:
sounds/

Dentro de sounds/ sube tus audios con estos nombres exactos:
start.mp3  -> antes motorola-start.mp3
end.mp3    -> antes motorola-end.mp3
join.mp3   -> puedes copiar el mismo motorola-start.mp3 y nombrarlo join.mp3

Luego abre:
https://mikest22.github.io/WALKIE-GRUPAL/index.html?v=10000

No borres tu respaldo index-estable-v300.html.
